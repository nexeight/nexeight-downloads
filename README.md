# Meesho Automation

Desktop automation software for managing Meesho product listing workflows with a multi-account control panel.

## Features

- Multi-account session management
- CSV-based product processing
- Image upload automation
- Category selection and listing flow automation
- LeftOff resume support
- Universal timing controls
- Manual template import support
- Live activity console
- Chrome/Selenium-based workflow automation

## How it works

This application helps automate parts of the Meesho supplier listing workflow. It reads product data from a CSV file, uses local product images, opens Chrome sessions, logs into configured accounts, and processes listing steps through the app interface.

## Requirements

- Windows PC
- Google Chrome installed
- Internet connection
- Authorized device access
- Valid account credentials
- CSV file with required columns
- Product images available locally

## CSV requirements

The application expects product data with required fields such as:

- FileName
- SecondIMG
- ThirdIMG
- FourthIMG
- StyleCode
- ProductName
- Price
- WPrice
- MRP
- Description
- Inventory
- Weight
- ManufacturerName
- ManufacturerAddress
- ManufacturerPincode
- PackerName
- PackerAddress
- PackerPincode

## Usage

1. Launch the application.
2. Add or configure account rows.
3. Enter account credentials.
4. Select the CSV file.
5. Select the image folder.
6. Set category and shipping threshold.
7. Start the selected account or run all selected accounts.
8. Monitor progress in the live console.

## Resume support

The app stores progress using a LeftOff system so processing can continue from the last saved row when needed.
